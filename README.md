### 🧠 About Me

I don't just train models; I build **production-grade ML pipelines** for cybersecurity. My focus is on the engineering required to move a model from a notebook to production: handling extreme class imbalance, calibrating probabilities, ensuring explainability (SHAP), and containerizing the stack (Docker, CI/CD).

- 🔭 **I’m currently working on**: Extending my Cyber Data Science portfolio with a Network Intrusion Detection System (CICIDS2017) and evaluating adversarial robustness.
- 🌱 **I’m currently learning**: Advanced MLOps patterns (MLflow, DVC) and zero-day anomaly detection.
- 💬 **Ask me about**: Asymmetric evaluation (FN=10xFP), isotonic calibration, SHAP, or how to build a threat model for an ML system.
- ⚡ **Fun fact**: I document all my bugs and failures in an "Incident Log" because that's where the real learning happens.
