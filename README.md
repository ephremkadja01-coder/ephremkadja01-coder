### 🧠 Who am I?

I am an ML Engineer specialized in **Cyber Data Science**. I focus on the end-to-end pipeline: from feature engineering and handling extreme class imbalance to asymmetric evaluation, SHAP explainability, and containerized deployment. 

I believe that in cybersecurity, a model without explainability is a liability, and a model without calibration is a guessing game. That's why I document my trade-offs, my threat models, and even my failures in an open **Incident Log**.

**Multi-Vector Phishing Detection** is a production-grade ML pipeline for classifying URLs and emails.
- **Architecture**: 18 URL features (Levenshtein, Punycode), 10 explicit text features + TF-IDF.
- **Engineering**: Isotonic calibration, SHAP TreeExplainer, URL/email score fusion.
- **Ops**: Asymmetric cost evaluation (FN=10x FP), CI/CD, Docker, Threat Model.
