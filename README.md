**Multi-Vector Phishing Detection** is a production-grade ML pipeline that analyzes both URLs (18 structural features) and email text (NLP + 10 explicit features). 
*   **Architecture:** Isotonic-calibrated XGBoost & Random Forest.
*   **Evaluation:** Asymmetric cost (FN=10x FP) and PR-AUC optimization.
*   **Ops:** GitHub Actions CI, Docker, SHAP TreeExplainer, and Gradio UI.
