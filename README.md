## 🚀 Featured Project

### 🛡️ Multi-Vector Phishing Detection — Cyber Data Science Pipeline
A machine learning pipeline for classifying suspicious URLs and phishing emails.
- **Architecture**: 18 URL features (Levenshtein, Punycode, TLD), 10 explicit text features + TF-IDF.
- **Engineering**: Isotonic calibration, SHAP explainability, URL/email score fusion, asymmetric cost evaluation (FN=10xFP).
- **Production**: CI/CD, Docker, Threat Model, Incident Log.
